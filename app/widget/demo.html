Chat widget demo

This page is served by the API itself and embeds the widget with one script tag.

Pick a site to talk to. On a real website the tenant is inferred from the page's origin; here it is passed explicitly.

Applying reloads the page with the options in the URL.

The tag this page is using:

Copy it into any page whose origin is listed for the site in tenants.yaml, drop data-site, and you are done.

Try: ask what the organisation does, switch language with the button in the header, press Stop mid-answer, reload the page and see the conversation restored.
